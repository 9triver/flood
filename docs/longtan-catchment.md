# 龙潭水库上游集水区

2026-10-05 接入用户提供的 `集水区/龙潭水库上游集水区.shp`。生成对象为 `Catchment/longtan_upstream`，通过 `reservoir_id=longtan` 与龙潭水库双向关联。原 Shapefile 为本地源数据；仓库中的 `domains/flood/data/objects/catchment.jsonl` 已包含运行所需的完整边界，部署时无需原文件或 pyshp。

## 数据与面积

- 1 个有效 Polygon，1 个外环，184 个坐标点（含闭合点）；保留全部原始顶点，不做简化、平滑或流域裁剪。
- 源坐标系为 WGS84 / UTM 49N（EPSG:32649），转换为 EPSG:4326 后供现有地图坐标转换链使用。
- 源 `area` 字段为 **35.4326735909 km²**。XML 元数据注明按 CGCS2000 高斯投影计算，单位平方千米。
- WGS84 椭球复算约 **35.43144900 km²**；差约 0.001225 km²（0.00346%），与源面积一致。直接按 UTM 平面计算约 35.40433312 km²，投影面积不可与其他计量方法混用。
- 本次将水库产流面积由 36 km² 校正为源 `area` 值（减少 1.5759%）。产流默认参数、三分区演进、面雨量加权展示和前端控制面积均取该对象的面积；区间 1 和区间 2 仍分别为 381、85 km²。
- 面积校正不代表已完成水文模型率定；降雨—产流模型仍采用原有演示参数。

源 `.shp`、`.dbf`、`.prj` 和 `.shp.xml` 的 SHA-256 记录在对象中。可在源文件就绪后重新导入：

```bash
uv run --no-sync --with pyshp python scripts/import_longtan_catchment.py
```

## 使用

“业务推演 → 三分区降雨 / 水库调度 → 定位水库集水区”显示并定位集水范围，同时显示关联水库。地图管理“水系与监测”可独立开关该图层，点击边界或名称标签可查看面积与关联水库；范围填色不拦截其他对象的点击。集水区是降雨产流的空间依据，预测淹没范围继续由水动力预测提供。

Agent 可查询 `Catchment`，沿 `reservoir_catchments` / `catchment_reservoir` 获取关联，并通过已有 `ui_show_objects`、`ui_focus_object` 显示与定位。
