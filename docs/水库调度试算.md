# 从原预测 t0 试算水库调度调整

用户在演进过程生成的24小时预测中选中未来 t1，要求调整水库调度并查看影响。
试算固定这版预测的 t0，以 t0 的水库状态续算，给出水库安全校核和淹没影响对比。
本功能只生成候选计算结果，不应用调度、不重置演进、不替换地图当前预测。

例如用户可以提出：

> 试算把水库改成目标下泄30立方米每秒，看看选中时刻X706的受淹情况是否改善，同时检查水库安全。

Agent 先查询该预测 t0 的方案，并查询 X706 对应的 RoadRoute ID，再提交候选参数。
如果目标模式或目标值不明确，应询问用户；不得自行把目标泄量设为零。

## Agent 工具

- `get_longtan_dispatch_plan(forecast_id="latest")`：查询所选预测 t0 的方案、
  精确水库状态及阈值。对话中的 `latest` 会在调用前绑定本轮预测版本。
- `simulate_longtan_dispatch(settings, forecast_id="latest", time_h=None,
  target_type="Road", object_ids=None)`：运行候选调度及水动力模型，比较同一范围的影响。
  `time_h` 省略时使用提问时冻结的地图选中帧；显式传入时需有精确预测切片。
  `target_type=RoadRoute` 配合 ID 可比较整条已收录编号道路；默认比较全部路段。

`settings` 是对 t0 原方案的调整，支持 `mode`（RULE / OUTFLOW / LEVEL）、
`target_outflow_m3s`、`target_level_m`、`normal_release_m3s`、
`outlet_capacity_m3s`、`max_release_m3s`。不接受初始水位、库容或预见期调整。
用户新指定的统一目标优先于原CSV目标；未改模式或目标时保留原逐时目标。
能力参数仅按用户明确要求调整，`max_release_m3s` 仍保留移植模型的覆盖语义。

## 时间与计算口径

1. 触发正式预测时，在其版本化输入文件中保存 `reservoir_dispatch_context`：
   t0 精确末库容、末水位、原全过程洪峰、方案、原调度过程和未来入库过程。
2. t0 对应已经完成的时段，其实际下泄保持不变。新模式从 t0 后第一小时开始，
   以精确库容续算。保留原模型的全过程洪峰分类和规则预见期所需的后续来水。
3. 水动力模型仍接收 t0 至 +24h 的25个边界点；只替换水库边界后24个点的实际下泄。
   其他三条边界、t0 边界值和模型时间基准与原预测一致。
4. 当前水动力模型根据流量历史特征预测水深，没有显式初始水深场接口。试算沿用原预测
   的特征构造方式；若两次结果含 t0 切片，还检查 t0 水深一致性。
5. 比较分别使用 t1 精确切片、整个24小时最大水深包络。包络结果不是 t1 状态，
   邻近积水不计为道路受淹，桥隧高程未知时保留未核实标记。

模型本体的调度规则不变；引擎新增可选 `initial_storage` 和 `input_peak_inflow`
用于延续已发生过程的库容和超标准洪水判定。没有这些参数时沿用原整段计算。

## 输出与失败处理

报告包含原方案和候选方案的实际下泄、逐时控制状态、最高库水位及发生时间，
以及 t1 和24小时包络的受影响数量、相交长度、水深、消除与新增影响对象。
计数覆盖完整所选范围，对象变化明细最多返回20项，完整空间分析另存文件。
目标值被泄流能力、安全泄量或应急规则覆盖时，按实际下泄解释结果。

水库校核以 t0 至 +24h 时段端点水位不超过校核洪水位为通过条件，设计水位超限
另列提示；实际水位超曲线且无法据此通过校核时返回未知。这是给定来水与能力
假设下的模型校核，不是工程安全保证。只有水库校核通过、所选范围在 t1 和
全期的原有淹没影响均消除且资料完整时，`candidate_satisfies_objective=true`。
校核失败的候选仍可返回淹没比较，但不会被认定为满足目标。

旧预测缺少续算快照、模型参数变化、缺少精确切片、水动力模型失败、无效水深或缺失网格
几何时，返回明确错误，不解释为无淹没。启用此功能后，需要由新的演进过程生成
一版包含续算快照的预测；不能用当前状态猜测旧预测的 t0。

候选文件保存在所属工作空间的 `dispatch_trials/<trial_id>/`：
`input.json`、`reservoir.json`、水深序列、`impact_details.json`、`report.json`。
候选水动力模型使用独立工作目录；正式预测版本、latest指针和演进数据保持原状。
工具仅加入用户对话，不加入自动事件的计算链，没有应用方案工具。
