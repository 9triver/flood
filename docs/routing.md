# 高德路线规划

`plan_route` 始终按避洪语义规划 `car` 或 `foot` 路线，不提供关闭避洪的模式开关。洪水约束由当前工作空间状态决定：

- 当前演示为 ready 且尚无演进时刻：按无洪水初始状态规划，`flood_validation=initial_dry`，不读取历史预测。
- 演进已开始：必须有匹配当前轮次、输入版本和时刻的有效预测；没有淹没区域时正常规划，有淹没时排除涉水候选，`flood_validation=checked`。
- 演进开始后预测缺失、过期或失败：返回 `forecast_unavailable`，不会按无洪水放行。

未演进的无洪水约定仅适用于当前状态；显式查询未来时刻或最大包络仍需有效预测。驾车默认禁行水深0.3米，步行0.15米。高德返回的 GCJ-02 几何转换为 WGS84；步行路线规划2.0一次请求最多三条候选。

路线校核使用完整湿网格多边形与完整路线求交，并用空间索引检索，避免中心点矩形与间隔采样漏掉局部淹没。

所有候选都违反淹没约束时返回 `no_safe_route`，不保存涉水路线。用户可改变交通方式、终点或指定时刻重新请求，不能通过选择普通导航绕过洪水校验。

高德 Web 服务配置在被 Git 忽略的 `.env` 中：

```dotenv
AMAP_WEB_SERVICE_KEY=your-web-service-key
```

规划结果会校验高德路线起终点与领域对象坐标的距离以及路线绕行倍率。默认最大端点距离为 800 米、最大绕行倍率为 10；超过限制时返回 `invalid_route`。动态规划结果保存在当前演进工作空间的 `routes/current.jsonl`，并通过 `EvacuationRoute` repository 与静态转移路线一起查询。历史版本保存在 `routes/archive/`，可按原路线 ID 复核，已发指令的路线引用不会因重新规划而丢失。
